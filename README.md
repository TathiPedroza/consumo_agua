# Calculadora e Analisador de Consumo de Água

![PyPI Python Version](https://img.shields.io/pypi/pyversions/python)
![PyPI Python Version](https://img.shields.io/pypi/pyversions/GitHub)
![PyPI Python Version](https://img.shields.io/pypi/pyversions/Energia)

Programa desenvolvido em Python para analisar o consumo mensal de água com base na categoria do usuário (comercial, casa ou apartamento) e fornecer recomendações personalizadas de uso.

## 🚀 Funcionalidades

* Aceita tanto entradas numéricas quanto textuais (ex: 1, um, casa, três).
* Utiliza a estrutura moderna `match-case` do Python para aplicar regras específicas conforme o tipo de imóvel e a faixa de consumo em metros cúbicos.
* Orienta o usuário sobre tarifas corporativas, padrões residenciais, controle econômico ou alertas de consumo excessivo.

## 📋 Pré-requisitos

* Para executar este programa, você precisará ter o **Python** instalado na sua máquina.
* **Nota:** Como o código utiliza a estrutura `match-case`, é recomendada a versão **Python 3.10 ou superior**.

## 🛠️ Tecnologias Utilizadas

* Python 3.10+
